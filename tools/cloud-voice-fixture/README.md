# 云真机固定语音样本工具

独立测试应用`com.vime.cloudfixture`，用于受控的云手机验收：提供一次性输入框、延迟播放的中英文合成样本，以及系统文件选择器内的只读测试文件。没有麦克风或联网权限。模型可由测试配方单独加入工具APK，用于只接受APK上传的平台；正常键忆主APK仍独立分发模型。

构建时传入`-PvimeCloudFixturesDir=<已核对的样本目录>`，目录中为`zh.wav`、`en.wav`，可选固定摘要的`x-asr-zh-en-q4_k.gguf`及相应许可证。不接收外部任意文件路径。文档提供器由`MANAGE_DOCUMENTS`保护，文件授权限定到`/document/`，只接受固定ID的读取请求。

工具安装包只用于测试，不作为输入法版本发布。扬声器播放样本能否进入手机麦克风，取决于云平台的音频路由；播放完成本身不算识别成功。应记录实际输入框文字、断网状态、最终主APK摘要，并清理测试数据与设备会话。浏览器麦克风权限弹窗须由用户处理。

0.1.9首次打开会安排系统Job执行固定样本原生检查；同签名主APK、专用检查APK都须已安装。任务不申请麦克风，不修改实际学习数据，不依赖前台页面持续存活。结果通过带随机会话标记的`ResultReceiver`回传，保存到本工具私有文件`last-job-offline-checks.json`，并以`JianyiOffline`标签输出固定样本报告与逐项结果，供云平台调试日志查看。报告包含实际主APK摘要、ABI、内存页、合成样本文字和耗时，不包含用户录音或输入文字。系统仅允许已经启动过的工具接收自身更新广播；重新安装不保证自动开始，需要至少打开工具一次。

「运行固定样本离线识别检查」按钮保留前台回传与显示方式，其报告另存为`last-offline-checks.json`。页面保持亮屏，可在系统锁屏上显示公开样本，不解除系统凭据保护。检查使用目标进程的独立缓存；报告不自动上传，不从后台启动界面。构建样本须为16kHz、单声道PCM16、44字节标准头WAV，与录音控制器输出一致。0.1.9的系统任务已在专用Android16、16KB页模拟器关闭WiFi/移动数据、无网络路由时通过11项检查并完成回传；ARM64云手机仍待验证。

系统SAF文档提供器仍受`MANAGE_DOCUMENTS`及限定URI授权保护。原生检查会重启目标进程，因此另设只读公共样本提供器：只暴露包内已公开许可的固定模型与两段合成音频，拒绝其他路径和写入，最多两路读取。它不包含用户文件、录音、输入文字或检查报告。正常输入法APK不包含上述任何测试提供器。
