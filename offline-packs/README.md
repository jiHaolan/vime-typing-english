# 键忆专业离线词包

手机下载一个或多个`.vimelex`文件，再到键忆「词包与查词 → 导入离线词包」安装。0.25.0起支持多个领域共存，也可以只安装`Jianyi-all-domains-2026.11.01.vimelex`组合包。使用和导入均不需要电脑。

文件中的`it`为计算机、`finance`为金融、`medicine`为医学、`law`为法律、`engineering`为机械工程、`bio-chem`为生物化学、`education`为教育、`business`为商务。每个包附来源、CC BY-SA 4.0许可、拼音生成器MIT许可与数据校验值。

`domain-packs.json`记录实际条目数、未覆盖种子与文件SHA-256；`domain-provenance.json`逐条区分CC-CEDICT来源序号和原创补充，不能将原创条目归为CC-CEDICT原文。`SHA256SUMS-packs.txt`可核对下载完整性。

完整说明见[词库核验与导入](../docs/LEXICON_COVERAGE.md)。
