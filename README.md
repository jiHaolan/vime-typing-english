# 边打字边背单词 · Vime

Android 中文输入法 + 英语提示 + 生词复习。先把打字做好，再利用日常输入认识和记住英文。

**当前代码：v0.22.1 开发测试版。** 修正多音字权重和简拼优先级，`e`不再把“我”当首候选；从固定来源重建 Rime 词典，按数据标识校验并升级公共文件。保留离线来源说明、学习备份与开关、全区域触感和电脑 X-ASR。ARM64 本地测试包约21.1MB；下方 GitHub 下载链接仍是0.16.0历史包。问题可通过 [Issues](https://github.com/jiHaolan/vime-typing-english/issues) 反馈。

## 已有功能

- Rime 全拼与九键、整句候选、候选展开和本地用户词频学习。
- 英文按键直接上屏，不需要额外确认；主动点击候选可补全单词。
- 中文候选上方显示一个简短英文义项；长按候选查看完整词卡、收藏或播放英文发音。
- 生词本、间隔复习、学习数据和估算遗忘曲线。
- 学习数据本机备份与恢复；合并保留本机同名词，替换需确认；可删除单个收藏及对应复习记录。
- 主题配色、按键触感、横竖屏独立键盘尺寸与自定义短语。
- 长按空格 2 秒调用手机语音服务，松手结束；默认无需填写 API 密钥。
- 可选离线词包、词典查询、剪贴板、表情和符号工具。

默认手机语音和英文发音使用已安装的服务；厂商服务可被检测到却拒绝实际识别。可选择[电脑X-ASR语音](docs/haolive-voice.md)，当前已在X100完成中文识别、由用户确认英文完整出字；该方案需要正在运行的电脑服务和有效连接，USB测试不等于已部署公共后台。APK不捆绑大型语音模型。

[免密钥语音设置与故障排查](docs/VOICE.md)：0.17.1 会将未配置的旧联网模式恢复为手机语音。
