# 键忆 · Jianyi

名称取“键盘”与“记忆”：每一次敲键，都积累一点记忆。桌面名称为「键忆」，系统输入法名称为「键忆输入法」，首页短句为“边打字，边记词。”。历史工程标识Vime、包名com.vime.ime及数据格式继续保留，避免破坏旧版覆盖升级。

图标将键帽作为外形，打开的书页作为主体，右侧金色书签表示记住一个词。图形不含文字，缩至48px时仍可辨认；底部轻微凸起表现按键层次。主图层使用108×108坐标，主体位于中间安全区域，适应圆形和圆角方形蒙版。

| 用途 | 颜色 |
| --- | --- |
| 深蓝背景渐变 | #21384F → #0B1322 |
| 暖白键面 | #F5F6F2 |
| 键帽底边 | #9FAFBE |
| 书页 | #182638 |
| 书签 | #E4B863 |

Android 8及以上使用独立背景与前景矢量；Android 13及以上另提供单色轮廓，由系统主题着色。旧版提供48、72、96、144及192px的PNG。不要把预览的圆角外框叠加到自适应图层上，也不要将文字或额外细线塞入书页。

源稿：[icon.svg](icon.svg)。生成器：[tools/make_icon.py](../../tools/make_icon.py)，需要构建电脑安装Pillow，不增加应用依赖。在工程根目录执行：

```powershell
python tools/make_icon.py --preview E:/Vime-build-work/jianyi-branding-20261101
```

该命令同步生成矢量、单色及PNG资源、SVG源稿，并导出方形、圆形、主题色和48px检查预览。仅运行`python tools/make_icon.py`也会更新全部源码资源。
