# 0.23.0：完整声调英文、来源与体积

候选英文、完整词卡和反查现在读取同一份固定CC-CEDICT4数据，删除旧`dict.android.json`和`LexiconSupplement.kt`。基础输入继续使用完整Luna/Essay公共表；分级标签独立提取ECDICT的word/tag。输入权重、英文与分级没有混合来源。

## 用户可见行为

- “重”输入zhong提示heavy，输入chong提示to repeat；“长”按chang/zhang匹配long/chief。同一个词存在不同拼写且不能唯一匹配时不猜提示。
- hao下“好”的词卡保留hao3/hao4及全部对应义项。同拼写不同声调的短提示仍用来源中的常用条目顺序，没有语境消歧模型。
- 长按候选查看完整声调词卡，发音/收藏沿用原有入口；查词页显示CC-CEDICT归属。旧收藏与复习不会被改写。
- 可选词包在原生引擎正常时也能优先提供完整编码候选；坏校验导入保留原包，移除后恢复内置查询。大型可选词包内存尚未验收。

## 体积与签名

Gradle增量ZIP曾留下大文件旧空洞。新优化器重建ZIP，仅重新压缩原DEFLATED条目，逐个核对所有有效载荷SHA，STORED原生库与resources保持存储形式；随后16KB对齐并用既有证书重新签名。没有删词、改原生二进制或放宽32MiB检查。

最终ARM64为31591204字节，32位ARM为29801256字节，x86_64为31558430字节。三个包都通过有效签名、对应ABI、原生ELF及ZIP对齐与体积核对；严格生产检查仍因debug、HTTP调试网络、预览证书三项失败，本轮未创建生产身份或公开发布。
