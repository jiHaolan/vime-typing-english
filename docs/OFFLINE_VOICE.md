# 手机独立离线语音

0.26.0候选版加入手机端中英文识别。导入模型后，不需要电脑、服务账号或API密钥；模型独立分发，主APK不包含模型。0.25.1公开版本仍只包含此前的语音方式。

## 使用

1. 首页打开「语音输入」→「离线语音 · 导入与管理模型」。
2. 下载指定中英文模型，返回应用，选择「导入已下载模型」。文件约93MB；应用检查大小和SHA256，错误文件不会覆盖已有的有效模型。
3. 点「在键盘中启用」，返回普通输入框，长按空格约半秒，看到「正在录音」后说话，松手结束。首次允许麦克风后，需要返回再长按一次。

中英文由同一模型识别。滑出空格、取消、收起键盘或切换输入框会放弃当前语音。每次最多30秒；缺少模型或权限时显示处理方法，不会自动改用联网服务。可在模型管理中移除模型，不影响打字和学习记录。当前32位安装包不提供离线识别。

离线模式在本机处理录音。结束、取消或失败后删除临时录音；进程意外退出时，下次语音组件初始化会清理遗留缓存。识别文字仍需检查，专有名词可能出错。手机语音、电脑语音和自定义联网服务属于另外的主动选择，数据处理方式见应用内说明。

本版发布页单独提供模型及`Jianyi-offline-voice-sources-0.26.0.zip`。后者包含可断网检出的固定上游Git源码、对应JNI配方、当前原生库及许可；无需下载源码包即可使用输入法。已有Rime与词典的来源包继续见0.25.0发布页。

## 当前验证范围

最终优化的0.26.0 x86_64候选包，在Android16、16KB页专用模拟器关闭WiFi/移动数据、无网络路由时通过10项固定样本检查：真实JNI中英文识别、模型事务与完整性、取消前后资源释放、模型移除，以及识别后Rime完整候选仍有英文。中文约4.259秒，英文约4.058秒，取消在实际计算回调开始后约24毫秒返回；这些时间只适用于该次测试。

中文合成样本“今天开始练习英语，欢迎使用键忆输入法。”返回“今天开始练习英语， 欢迎使用建议输入法”，品牌名识别错误保留。英文返回“Hello. Nice to meet you. Today we practice English.”。不据此声明口音、噪声、中英混说或总体准确率。

最终候选另通过离线选择返回、旋转及进程重启保持、实际麦克风授权/拒绝/重试，以及禁用主机音频的模拟器收音无误出字、临时文件清理检查。最终x86_64 APK也已在关闭WiFi/移动数据后，通过系统文件选择器从Downloads导入模型，核对私有存储中的完整SHA256，并实际点击启用、返回已选离线模式；观察区间未记录本应用ANR事件。结束后恢复原APK、数据库、偏好和网络，移除本轮模型与下载文件。早期私有原型的一次前台无响应日志继续保留：线程转储失败，尚无足够堆栈确认阻塞根因，这次通过不作为根因已修复的证明。

ARM64云真机和真实麦克风识别仍在继续验证。X300、X300 Pro Android16已安装这份候选及内部检查工具，但远程触控未能进入测试界面，尚未取得识别报告；这些安装结果不计作语音通过。X300会话已释放，X300 Pro页面交给用户协助进入测试工具。正式商店验收、长音频、低内存、耗电及更多机型检查尚未完成。早期单线程/四线程原生探针结果继续保留，不替代最终APK验收。
