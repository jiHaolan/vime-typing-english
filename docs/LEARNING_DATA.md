# 学习数据管理

入口：生词本 → 数据管理。0.18.0新增此功能，正常打字不需要访问文件或授予存储权限。

“备份学习数据”使用Android系统保存窗口，导出主动收藏的词、完整基础间隔复习进度及最近10000条实际复习记录。超过保留窗口的历史不会补造；词条的累计复习次数继续保留。文件是可查看的UTF-8 JSON，请存放在自己保管的位置。

备份不包含输入正文、剪贴板、用户词频、录音、API密钥、设备身份或其他设置。应用不自动上传备份；若在系统窗口选择第三方网盘，文件由所选文件服务保存。

导入时先完整读取并校验文件，再展示词条、记录数、备份日期和少量词条预览。支持本应用版本1的学习备份，最多3000词、10000条历史和16MB；不支持任意词典包、Excel文件或其他软件的存档。

- **合并导入**：只加入本机缺少的词及其历史。本机同名词的释义、进度和历史保持原状。重复合并不会增加重复记录。
- **替换本机学习记录**：二次确认后，整体替换当前收藏、进度与复习历史。建议先导出当前备份。
- **放弃导入**或取消系统文件窗口：不更改本机学习记录。
- **移除收藏**：在生词本对应词卡上操作，经确认后同时删除该词的复习历史。
- **清空收藏与复习记录**：经确认后删除这两类数据，不清除输入法设置、个人词频或键盘释义显示状态。

收藏与复习改用SQLite。读取、保存、迁移和导入均在后台线程执行；事务同时维护词条与关联历史。复习提交完成后才更新完成数，旧页面或重复点击不会重复记成绩。首次升级时从旧SharedPreferences迁移，成功打开并校验数据库后清理旧副本；失败保留来源数据并显示错误。

损坏的备份或事务中途失败不会覆盖正常本机记录。数据库本身严重损坏时保留文件并显示读取错误；当前尚无损坏数据库的一键修复流程，请保留应用数据并反馈，避免卸载导致现有文件被清除。

文件预览和待导出的数据通过ViewModel保留，旋转屏幕不会把大备份塞进状态Bundle。系统终止整个应用进程后，尚未提交的预览需重新选文件；不会自动替换本机记录。
