# 0.24.0 月光玻璃界面

根据用户指定的[StyleKit玻璃拟态](https://www.stylekit.top/zh/styles/glassmorphism)研究并实现。视觉参考苹果风格的中性玻璃、圆角、系统字体和清晰层次；交付仍是原生Android应用，不是iOS安装包。

## 已实现

- 默认皮肤0改为“月光玻璃”。浅色为冰白、钢蓝背景与高对比度金色主操作；深色使用夜航蓝、月光光池和克制的香槟金。其余皮肤序号和自定义配色入口保留。自定义配色不叠加光池，尊重用户选择的页面和键盘底色。
- 首页把今日复习与试打入口作为主要层次；复用真实收藏/待复习数量，不添加演示成绩。设置入口采用同一套线性图标，统一字号、圆角与留白。
- `GlassUi`复用静态背景光池、中性半透表面和顶部高光；不抓取其他应用的画面，不模糊文字，不在按键路径执行实时背景模糊，也未添加字体下载或新UI依赖。
- 键面增加细边缘，按下反馈不移动键位；空格、深色动作键和按键预览使用正确的主题前景色。候选仍以大号中文为主，上方英文只占一行。
- 词卡增加独立可读底色；英文答案、发音入口与中文回忆词放在同一张复习卡里。“查看答案”主按钮简化文案，避免大字体下冗长换行。
- 键盘、词卡和工具面板分别保留系统导航安全区域，用户自定义底部距离在其上叠加；横向避让导航与屏幕缺口。浅色导航区使用深色系统图标。遵循Android [Views边缘区域说明](https://developer.android.com/develop/ui/views/layout/edge-to-edge)。
- 词卡进入时取消缩放，系统关闭动画时立即显示。原生输入、候选词库、学习数据和语音接入方案沿用已验证版本。

## 范围与验证

本分支从`cc225a4`建立，分支名`codex/ios-glass-ui`，版本0.24.0/code37。上一分支尚未完成的0.23.2原生源码依赖接入保持暂停，未混入本次UI包；原生`.so`与0.23.1逐字节相同。

检查包括构建/JVM/lint、原有窗口与真实触摸/返回流程、实际深浅色截图、375dp与200%字号、横屏输入和减少动画。具体产物摘要、通过数、失败保留与模拟器恢复收据见`verification/glass-ui-0.24.0.json`。颜色报告中的72组是资源前景/表面对比检查，不能据此声称所有动态叠色和任意自定义配色都已验收。

初次资源生成使用了不同XML前缀，ViewBinding未生成主页字段；已恢复Android前缀并重新构建。一次窗口检查被Android CLI的UiAutomation连接占用，清理检查工具后串行执行通过。视觉检查发现透光表面会透出系统阴影，去掉该阴影后保留边缘层次；随后实测发现导航按钮覆盖底排，补充独立安全区域。旧构建和失败收据在外部证据目录保留。

本次只使用专用模拟器，不安装或复测个人手机。APK使用已有预览证书，仍不等于正式商用签名发布；没有公开推送。完整商用目标仍有独立语音、签名、收费与多设备长期验证等后续事项。
