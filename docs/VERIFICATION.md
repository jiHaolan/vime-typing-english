# 0.16.0 验证与交付

本轮修正英文待确认/128字符截断、轻微滑动串键/间隙漏触、过长候选释义，增加词卡、生词本、复习答案和查词主动英文发音。英文直接commitText；主动选择补全才替换已核对的当前前缀。中文仍走Rime，不声称已测得真人误触率或所有候选都准确。手机语音输入沿用0.15；主页旧的“需配置密钥”页脚同步修正。

## 失败与复测记录

旧0.15对照18项中8项失败、10项通过：复现英文composition、回车先确认、连续128字符后丢输入、水平串键、垂直缝隙漏触，以及缺少发音按钮。初次模拟器系统挂起/冷启动键盘未就绪，保留启动失败记录；恢复时仅移走确认无进程使用的陈旧锁，未清除虚拟机数据。

首次多义词检查未等到扩展英文注释出现；改为等待实际注释再打开词卡后通过。早期学习页脚本未恢复滚动位置，错误报告找不到复习按钮；改为先滚回顶部。系统设置冷启动检查过早、主页查词入口的一次物理点击未生效，改为等待真实窗口/通过无障碍点击实际按钮后补测。显示检查首次在宿主窗口未稳定时超时，关闭测试打开的系统设置并等待实际宿主位于前台后复测。配色修订期间曾出现中间包与交付指纹不同，已主动停止旧包显示测试并在配色修正版重新完成38项功能测试；该次“Process crashed”来自主动停止测试宿主，不是产品崩溃。大字体截图还发现居中词卡标题被裁，最终仅将词卡XML改为顶部对齐，增加标题必须完全位于输入法窗口内的断言，复测四种配置。原始失败和补测均保留，没有删除失败记录或把受控语音回调当作ASR效果。

旧静态脚本仍禁止0.15已经支持的语音输入法回退，本轮将此陈旧断言更新为：无通用切换弹窗，仅列出已启用的voice子类型。产品回退逻辑未为通过断言而改变。

## 使用与限制

长按候选→播放英文发音；生词本、复习答案与查词页同样可播放。只把用户主动选择的词条/首个义项发给手机TTS引擎，不朗读或上传聊天段落。手机可能需要英语语音包或网络，缺少时点发音设置；本应用不内置发音模型，不要求API密钥。停止页面或关闭词卡会停止播放，迟到回调不会启动下一次播放。

vivo真机的误触改善、扬声器/蓝牙、英语音包、音量和音色待用户复测。此次模拟器检查不能替代真人输入与听感测试。详细用法见更新说明。

API依据：[Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech)。Rime与词库来源、许可证、原生哈希随完整源码提供。
