## 实施与验收

上线前应核实个人主体能否使用拟选支付渠道，落实商品价格、服务期限、订单校验、到期、重复回调、退款及恢复购买。到期不删除个人收藏、复习或词包，基础功能继续可用；新版权益不能只靠修改本机标志解锁。

不得在没有真实收款和恢复、退款处理能力时展示“支付成功”或开放销售。正式服务使用新的网络能力或第三方 SDK 时，同步更新隐私政策、权限及商店声明。当前不为计费上传输入原文。
