# 当前版本的数据处理

中文候选、用户词频、生词本、复习记录、自定义短语和设置主要在本机处理。应用不内置账号、广告 SDK 或自动反馈上传。不会为云端计费统计而上传聊天全文；当前版本尚未实现用量计费。

麦克风权限只用于用户主动启动的语音输入。默认调用用户选择的手机语音服务，其网络使用和数据处理由该服务负责。高级自定义转写接口只有在用户主动选择并配置后才运行；密钥通过 AndroidKeyStore 加密保存。音频临时缓存会在完成、失败或取消后清理。

0.17.2 起仅在本机保留最近一次手机语音尝试的服务名称和标识、请求语言、阶段及错误码，每次尝试覆盖旧记录，不保存录音或识别文字。只有主动点击“复制语音故障信息”时，才将这些状态及手机型号、Android 版本、输入法版本放入系统剪贴板；不会自动发送到聊天或反馈平台。

词条发音只将用户主动选择的英文词条/首个义项交给手机文字转语音引擎；该引擎可能联网或需要下载英语语音包。关闭词卡或离开学习/查词页面会停止播放。

密码输入不展示学习候选，不记录学习数据。反馈 Issue 是 GitHub 上的公开内容，请自行遮住私人聊天、账号、密码和密钥。应用没有自动向 Issue 附加聊天记录的功能。
