# 当前版本的数据处理

中文候选、用户词频、生词本、复习记录、自定义短语和设置主要在本机处理。应用不内置账号、广告 SDK 或自动反馈上传。不会为云端计费统计而上传聊天全文；当前版本尚未实现用量计费。

0.18.0起，主动收藏和复习记录保存在本机SQLite数据库。升级验证迁移成功后清理旧存储副本。用户可在生词本移除单词及对应复习历史，或在数据管理中清空收藏与复习记录；该入口不清除其他输入法设置和个人词频。

0.20.0起，首页「输入数据」提供分项清理并要求确认：重置选词习惯会清除应用词频和Rime用户词典；重置英文提示状态会清除已掌握标记、本周隐藏和曝光积累。这两项都保留收藏与复习进度。自定义短语、最近符号/表情、临时剪贴板历史、最近一次语音故障记录可分别清除。短语删除前可先导出。清理不会自动停止之后的选词学习或新的语音状态记录。

临时剪贴板历史仅在用户主动保存后留于本应用内存，最多10条，取用时排除超过10分钟的记录，输入法服务销毁时清空；没有磁盘副本。「输入数据」页只清空这份临时历史，不读取或更改系统剪贴板。语音故障记录的清理保留已配置的服务与密钥；可从该页前往「语音输入」单独清除已保存密钥。

0.21.0起，「输入数据」可分别关闭后续选词学习和打字曝光。选词开关控制应用词频与Rime学习写入，关闭后已有记录仍可影响候选，可另行重置。曝光开关控制打字积累的英文熟悉度；主动收藏、复习及已掌握等明确操作继续保存。设置在后台提交成功后显示确认，进程重启后继续生效。升级保留原有默认开启行为，不将此开关当作正式服务的完整授权机制。

同页新增本地「隐私与数据说明」，描述输入、备份、临时历史、语音、发音、故障信息及清理方式，打开时不请求网络或新权限。只有主动点击反馈链接才打开GitHub网站。当前为预览版本，正式经营主体、线上语音处理方式和商用条款仍需在相应服务上线前明确。

本应用生成的0.21.0本机故障文件只保留固定阶段、线程类别、异常类型与有界的代码位置，不记录异常消息、原始线程名、源文件名或suppressed内容。旧版`last_crash.txt`在启动时删除；新版报告可在「输入数据」清除，也可在下次启动时主动查看或复制，没有自动上传。本约束针对应用自行保存的报告，不改变Android系统自身的诊断日志。

学习备份只在用户主动操作时，通过Android系统文件窗口写入或读取用户选择的位置，不申请广泛存储权限。备份包含收藏、复习进度和最近10000条复习记录，可直接查看；不包含输入正文、剪贴板、词频、录音、密钥或其他设置。若用户在文件窗口选择网盘，备份将交给所选文件服务。系统自动备份和设备转移不复制本应用的学习数据库。

麦克风权限只用于用户主动启动的语音输入。默认调用用户选择的手机语音服务，其网络使用和数据处理由该服务负责。高级自定义转写接口只有在用户主动选择并配置后才运行；密钥通过 AndroidKeyStore 加密保存。音频临时缓存会在完成、失败或取消后清理。

“电脑语音”模式在松手后把本次WAV录音发送到用户配置的HaoLive地址，不使用API密钥；电脑上的识别模型不打包进APK。服务的数据处理由服务持有人负责，USB测试地址只连接本次测试电脑，没有自动开通公共语音后台。

0.17.2 起仅在本机保留最近一次手机语音尝试的服务名称和标识、请求语言、阶段及错误码，每次尝试覆盖旧记录，不保存录音或识别文字。只有主动点击“复制语音故障信息”时，才将这些状态及手机型号、Android 版本、输入法版本放入系统剪贴板；不会自动发送到聊天或反馈平台。

词条发音只将用户主动选择的英文词条/首个义项交给手机文字转语音引擎；该引擎可能联网或需要下载英语语音包。关闭词卡或离开学习/查词页面会停止播放。

密码输入不展示学习候选，不记录学习数据。反馈 Issue 是 GitHub 上的公开内容，请自行遮住私人聊天、账号、密码和密钥。应用没有自动向 Issue 附加聊天记录的功能。
