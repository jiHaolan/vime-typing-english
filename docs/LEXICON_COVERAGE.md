# 词库完整性与专业词包

0.25.0将文件完整性和实际英文显示分别核对。输入库保留569466条词语/读音记录，英文库保留121093个词头、122472个声调组及198019个义项；原有拼音表、英文映射文件和原生库不做删减。

固定覆盖基线为已锁定jieba词频表的前10000个多字词及前500个单字，另补常用口语。它是一份可重现的验收清单，不代表汉语所有词语或整句翻译。专名可显示转写，数词量词使用明确规则；新短释义与CC-CEDICT原始释义分开保存并单独标明来源。未知词不拼接零碎释义冒充翻译。

新增1253条补充记录，覆盖默认标签空缺、只有数字的标签及常用口语。读音匹配时仍优先采用原始词典；其他读音和完整义项继续可在词卡查看。全拼、九键、简拼与补全都校验读音提示，避免将“长”的不同读音混成同一释义。

## 手机上导入专业词包

在手机浏览器打开[0.25.0下载页](https://github.com/jiHaolan/vime-typing-english/releases/tag/v0.25.0)，下载所需`.vimelex`文件。打开键忆 → 词包与查词 → 导入离线词包，在系统文件选择器中选中下载文件，查看来源后安装。下载完成后的查询、候选和词卡在手机本地运行，不需要电脑。

可按领域安装，也可选`Jianyi-all-domains-2026.11.01.vimelex`组合包。通常选择其中一种方式即可。领域之间有重叠，表内数量不能直接相加当作独立词头总数。选词规则、逐条来源序号和文件哈希随[词包目录](../offline-packs/)提供；这是领域学习词库，不宣称穷尽所有行业术语。

0.25.0支持最多16个扩展包共存，压缩数据合计32MB、词条合计24万。同一标识的新版本更新旧包；同词同读音由最后导入的包优先。可移除单个包或全部扩展包，收藏、复习与内置词库保留。旧版`.vimelex`仍能导入，原`active.vimelex`在首次成功变更后迁入多包目录。

导入会先校验格式、四个限定文件、UTF-8、词条数及SHA-256，再构建完整下一版索引，最后原子更新目录。校验或构建失败时保留已安装词库；不执行词包中的代码。损坏的扩展目录可从页面清理后重新导入。

## 来源与重建

专业包使用固定CC-CEDICT快照的种子词与明确领域标记筛选，补足另列的原创专业词条，遵循CC BY-SA 4.0。拼音生成使用pypinyin0.55.0（MIT），仅构建时使用，不打入APK；相应原始许可随包和应用保留。

```powershell
python tools/build_common_english.py --prepared <已验证CC-CEDICT导出目录> --pypinyin-path <pypinyin0.55.0目录> --jieba-source <固定jieba字典> --output <新输出目录>
python tools/build_domain_packs.py --prepared <已验证CC-CEDICT导出目录> --pypinyin-path <pypinyin0.55.0目录> --output <新输出目录>
```

生成器拒绝不匹配当前英文资产来源哈希的旧导出。`data/`保存常用词、常用字、领域选词与新增释义；`offline-packs/`保存独立导入包、来源映射和摘要。验证报告记录本轮实际APK、JVM与Android检查范围；模拟器结果不能替代全部手机与语音识别验收。
